A program that draws a newspaper front page summing up the world news of Monday 23 November 2026 and writes it to `/output/entry.png`. Node 22, standard library only, no network: every pixel is drawn in code with a built-in 5x7 bitmap font, so every word is crisp and legible.

The front page covers the day's biggest stories: a Russian warship sunk by sea drones at Benghazi in Libya, the COP31 climate talks collapsing with no deal in Antalya, Mexico capturing cartel boss 'El Chapo Isidro' in Sinaloa, the Strait of Hormuz war widening to a US base in Bahrain and Saudi Arabia, and markets bracing for a 'Black Monday' after Friday's worldwide sell-off — plus the Indonesia factory fire, South Korea's education minister resigning over an AI cheating scandal, and India's record 720/9d in the Wellington Test.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
